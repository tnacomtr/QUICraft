# Gotchas

- **Native reordering fixture needs an explicit window:** `NativeFeaturesTest`'s comparative relaxed-loss ratio was calibrated at cwnd10. Inheriting the new default64 failed8/8 controls versus5/5 passes at10. Pinning this capability fixture to10 preserves its old assertions; a separate byte-exact2MiB transfer covers64. This is not evidence of reorder performance parity at64. (src: independent verifier/superior diagnosis and `af53885`, 2026-10-13, verified)
- **Strict updater parsing is not authentication:** the separate Java21 module parses bounded immutable schemas only. Successful parsing does not imply signatures, freshness, sequence floors, revocation coverage or permission to stage a jar. Keep these as separate reviewed layers. (src: `DocumentParser` contract and verifier `9e49a57`, 2026-10-13, verified)
- **TCP-only protection can be bypassed by origin UDP:** confirm provider coverage of the actual QUIC address and port before opening it; TCP frontend coverage is not sufficient and UDP exposure can harm the shared TCP link. (src: owner-doc security review and `docs/server-security.md` section4, 2026-10-13, verified)
- **Antigravity model IDs are agy aliases, not display names:** `claude-opus-5.5` fails model selection ("not recognized as a known model") and stalls the skill at its first command; the working family alias is `claude-opus-5-5`, with `--effort` selecting the variant (cli.log: `model alias "claude-opus-5-5" resolved to "claude-opus-5-5-medium"`). Gemini keeps its dot: `gemini-3.8-flash`. Fixed in all three `agent_config.yaml` copies. (src: antigravity-subagent smoke test, exit 0 with commit dde3303, 2026-10-14, verified)
- **One Gradle build per worktree:** a verifier and a coder running Gradle in the same worktree at once corrupted test results (stale or missing XML, inflated totals). Run gates in a worktree only after the coder finished, and use `--rerun-tasks` when counting. (src: 4F gate runs, 2026-10-14, verified)
- **opencode detached runs do not notify:** poll the log until its size is stable for 90 s and it contains `RESULT:`; a 0-byte log can mean a hung start. (src: gate.sh runs, 2026-10-14, verified)
- **EnumSet cannot mix OpenOption kinds:** `StandardOpenOption` and `LinkOption` are different enums; use `Set.of(CREATE_NEW, WRITE, NOFOLLOW_LINKS)` for `Files.newByteChannel`. (src: 4Fb marker write, 2026-10-14, verified)
- **Updater host-failure tests:** `SourceFetcher` throws `FetchException`; a corrupt `state.json` is the reliable way to force a host failure in facade tests. A disabled runtime returns before argument parsing, so it cannot test command translation: use a recording dispatcher. (src: 4F/4V tests, 2026-10-14, verified)
- **Fabric mixin guards:** wrap the WHOLE injected body in try/catch(Throwable): linkage errors are thrown at the call site inside the mixin, not inside project code. Work queued to the server thread needs its own guard inside the task. (src: 4Fa reviews, 2026-10-14, verified)
- **Fabric loader API:** `ModOrigin` is in `net.fabricmc.loader.api.metadata`. Loom `genSources --offline` can fail after a "disowned lock"; it worked once online. (src: 4Fa unit, 2026-10-14, verified)
- **Updater readers check-then-open:** `isRegularFile(NOFOLLOW)` then open can block on a FIFO swapped in between; keep such reads off start/main threads or check after open. (src: 4Fb security review, 2026-10-14, low)
- **External coders must not read decompiled game sources:** briefs for opencode/agy/DeepSeek roles must say "do not read, open or quote decompiled or remapped Minecraft sources (scratchpad src26/src1211, Loom caches); confirm targets by compile probes and mappings files only". A 4Fa round-2 DeepSeek run read a few lines of the scratchpad decompiled `DedicatedServer` because the brief only forbade copying. (src: code-4Fa2 report, 2026-10-14, verified)
- **Updater clocks must tick in whole seconds:** `CanonicalJson.timestamp` rejects sub-second instants, and `Clock.systemUTC()` makes them, so every real stage threw (journal `created`, `tornSince`) while unit tests with fixed clocks passed. The production seam uses `Clock.tickSeconds(UTC)`. Any new persisted timestamp must come from that clock. (src: mock-host integration and `7ba4658`, 2026-10-14, verified)
- **New worktrees need the native build:** copy `natives/build/out` from the main tree, or the build fails with "patched Netty QUIC build is missing". (src: mockhost worktree, 2026-10-14, verified)
- **DeepSeek coder shell limits:** through opencode it can run `./gradlew` but not `java`, `curl` or `git -C`; brief it to prove behaviour with tests, and run child JVMs or live smokes yourself. (src: mockhost unit, 2026-10-14, verified)
- **JUnit `@Timeout` does not bound pipe reads:** `readLine()` on a child process's stdout ignores interrupts; drain on a daemon thread into a queue and poll with deadlines, and `destroyForcibly()` before closing the reader. (src: Astra review of MockReleaseHostTest, 2026-10-14, verified)
- **Known core flake under the full build:** `QuicLoopbackTest.aPeerThatDoesNotReadMakesTheStreamUnwritableUntilItDoes` failed 2 of 5 fresh root builds (once in `:core:test`, once in `:core:testUpstreamNative`; "a stalled peer must make the stream unwritable", QuicLoopbackTest.java:403) and passed 3/3 isolated and 2/2 under four parallel test tasks. Not caused by updater work. Root cause open: the writer stayed writable after 64 MiB although the windows are 8 MiB stream / 16 MiB connection, so something granted credit. (src: final builds on feat 8ee0aa8, 2026-10-14, verified flake; cause unverified)
