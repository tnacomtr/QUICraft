API (class `SequencePolicy`, all static):
1. `long manifestFloor(StateRecords.Snapshot snap, UpdateDocuments.Trust trust)` = max(trust.manifestSeqFloor, snap.state().revocations().minManifestSeq(), max seqByKid[kid].seq over kids whose kid is NOT Hex.kid(p) for any p in snap.revoked().revokedPubs()). Persisted kids absent from the trust file still count.
2. `ManifestDecision manifestDecision(VerifiedDocument<ReleaseManifest> m, StateRecords.Snapshot snap, UpdateDocuments.Trust trust)` -> enum-like record (`ACCEPT`, `REPLAY_SAME` (seq == floor and identical sha256 to the persisted seqByKid entry with that seq for one of the signing kids), `STALE` (seq < floor, or == floor without identical hash -> treat == floor with a different hash as `EQUIVOCATION`)). sha256 = Hex.sha256(m.exactBytes()). Only signers with RELEASE role that are not revoked count.
3. `StateDelta mergeRestrictions(StateRecords.Snapshot snap, VerifiedDocument<Revocations> doc)`: precondition the doc is signed by the CURRENT revocation key: some signer pub equals snap.state().revocationKey() and that pub is not revoked; otherwise return an unchanged delta. Adds revokedKeys (dedupe by pub) and blockedArtifacts (dedupe) to the permanent union, maxes minManifestSeq into state.revocations (keep other revocations fields). No expiry, seq or issued condition. Then prune (docs growth policy): seqByKid entries and withdrawn entries of kids of revoked pubs.
4. `StateDelta selectCurrent(StateRecords.Snapshot snap, List<VerifiedDocument<Revocations>> docs, Instant systemNow)`: considers only docs signed by the current revocation key (as in 3) with issued <= systemNow + 24h (FreshnessPolicy.futureIssued false) and structural times valid (FreshnessPolicy.structuralTimesValid with REVOCATIONS_MAX_LIFETIME).
   - Non-seed (persisted sha256 non-empty): the highest seq doc with seq > persisted seq becomes current; a doc with seq == persisted seq and a different sha256 is equivocation (record it in a returned warnings list; no state change from it); none qualifying -> keep persisted current (named gap: never cleared by absence).
   - Seed (sha256 ""): highest-seq doc with seq >= persisted seq becomes current, expired allowed. Two docs with the same highest seq and different sha256 -> equivocation, no change.
   - Becoming current sets seq, sha256 = Hex.sha256(exactBytes), issued, expires; minManifestSeq = max(persisted, doc). Also apply mergeRestrictions for every considered doc (restrictions merge regardless).
   - Return a `SelectionResult(StateDelta delta, List<String> warnings)`.
5. `boolean freshRevocations(StateRecords.Snapshot snap, UpdateDocuments.ReleaseManifest manifest, UpdateDocuments.Trust trust, Instant effectiveNow)` = not seed, expires > effectiveNow (FreshnessPolicy.unexpired), seq >= trust.revocationsSeqFloor, seq >= manifest.minRevocationsSeq.
6. `boolean stagingCoverage(StateRecords.Snapshot snap, Map<String, VerifiedDocument<Revocations>> currentByOrigin)` where keys are distinct origin keys (only "modrinth", "github", "sudoe" count; others ignored): true when at least 2 entries have Hex.sha256(exactBytes) equal to snap.state().revocations().sha256() (non-empty). A Map cannot hold the same origin twice; document that aliases/retries must be collapsed by the caller.
7. `StateDelta acceptManifest(StateRecords.Snapshot snap, VerifiedDocument<ReleaseManifest> m, String compiledPlatform, UpdateVersion maxRunningOrOnDisk)`: only if manifestDecision is ACCEPT or REPLAY_SAME (else unchanged delta). For each verified, non-revoked RELEASE signer kid: seqByKid[kid] = max by seq (KidSeq(seq, sha256, issued)); add withdrawn entries from m.document().withdrawn() whose platform equals compiledPlatform and version > maxRunningOrOnDisk, each with that kid (first signing kid in sorted order), dedupe by sha512. Enforce caps (seqByKid <= 32, withdrawn <= 256): if exceeded, return unchanged delta and a "state full" flag (`AcceptResult(StateDelta, boolean stateFull)`).
8. Tests (`SequencePolicyTest`): build VerifiedDocument instances using the 1.2 test helpers (TestKeys, signed fixtures) through AuthenticatedDocuments so evidence is real. Cover: floor ignores revoked kid and counts kid absent from trust; equivocation at equal seq; replay same accepted; restriction merge from an OLD or EXPIRED doc still merges; restriction merge ignored when signed by a non-current revocation key; seed picks highest seq regardless of list order; seed accepts expired; seed equal-seq conflict -> no change + warning; non-seed keeps persisted when nothing new; future-issued doc never current but its restrictions still merge (spec R8); freshRevocations cases; coverage 2-of-3 true, 1-of-3 false, unknown origin ignored, stale persisted sha mismatch false; acceptManifest raises floor so an earlier manifest (lower seq) becomes STALE afterwards (invariant 8); withdrawn only own platform and newer versions; caps -> stateFull.
