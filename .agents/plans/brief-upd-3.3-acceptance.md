API (class `Acceptance`, static):
1. `RevocationAcceptance evaluateRevocations(HostCollection responses, ReleaseHosts configured, StateRecords.Snapshot current, UpdateDocuments.Trust running, Instant systemNow)`:
   - currentTrust = TrustSnapshot.of(running, current.revoked().revokedPubs()).
   - For each HostEvidence: ignore (diagnostic) if !configured.contains(host). Not OK -> diagnostic "<key>: revocations fetch failed (<OUTCOME>)". Else AuthenticatedDocuments.verifyRevocations(doc, sig, currentTrust): TORN -> torn handling (below); BAD_SIGNATURE / MALFORMED -> diagnostic; VERIFIED -> collect.
   - delta = SequencePolicy.selectCurrent(current, currentTrust, collected, systemNow); its warnings go to diagnostics.
   - Torn handling on the resulting state: for a torn host, tornSince.putIfAbsent(key, systemNow); if systemNow is more than 24 h after tornSince[key], add diagnostic "<key>: torn for more than 24 h" (the caller rate-limits WARNs). For a host whose pair VERIFIED, remove it from tornSince. Return the combined delta (build a new UpdaterState; never mutate).
2. `ManifestAcceptance evaluateManifests(HostCollection revocationResponses, HostCollection manifestResponses, ReleaseHosts configured, StateRecords.Snapshot current, RuntimeIdentity id, UpdateVersion onDiskVersion, CheckMode mode, Instant systemNow)`:
   - `current` is the snapshot AFTER evaluateRevocations was committed (the caller re-reads it). Rebuild currentTrust = TrustSnapshot.of(id.runningTrust(), current.revoked().revokedPubs()).
   - clockFloor = ClockFloor.of(trust.built(), current.state().revocations(), current.state().seqByKid(), revoked kids (Hex.kid of revoked pubs)); effectiveNow = FreshnessPolicy.effectiveNow(systemNow, clockFloor); if FreshnessPolicy.clockBehind(systemNow, clockFloor) add diagnostic "system clock is behind the clock floor".
   - For each manifest HostEvidence (configured host, OK): verifyRelease under currentTrust; torn handling as above; VERIFIED -> M6: structuralTimesValid(issued, expires, MANIFEST_MAX_LIFETIME) && !futureIssued(issued, systemNow) && unexpired(expires, effectiveNow), else diagnostic and skip. Then SequencePolicy.manifestDecision(m, snap, trust, currentTrust): ACCEPT or REPLAY_SAME -> SequencePolicy.acceptManifest(snap, m, trust, currentTrust, id.platform(), max(id.runningVersion(), onDiskVersion)) and fold its delta into `snap` for the next manifest (stateFull -> remember, stop accepting further manifests, no candidate); STALE/EQUIVOCATION/UNTRUSTED -> diagnostic.
   - Highest accepted seq wins (M8). artifactSources = the configured hosts (in configured order) whose VERIFIED manifest bytes are identical (sha256) to the winner's.
   - Entry selection: entries with platform == id.platform() and targets containing id.target() exactly, version > max(id.runningVersion(), onDiskVersion), sha512 not in folded revoked.blockedArtifacts and not in folded state.withdrawn sha512s and not in the winner manifest's own withdrawn list for this platform; pick the highest version (ties impossible by schema; if equal versions appear, pick none and add diagnostic).
   - REPORT mode: candidate only if SequencePolicy.freshRevocations(folded, winner, trust, effectiveNow).
   - STAGE mode: additionally require coverage: re-verify every OK revocation pair from revocationResponses under currentTrust, keep VERIFIED ones keyed by host key, and require SequencePolicy.stagingCoverage(folded, currentTrust, thatMap). Otherwise no candidate + diagnostic naming which hosts did not match.
   - ManifestEvidence from the winner's exact doc + sig bytes. Return the folded delta (manifest floors/seqByKid/withdrawn plus tornSince updates) even when there is no candidate.
